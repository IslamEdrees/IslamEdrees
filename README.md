## 🔥 CASE STUDY — One-Way Audio

```bash
Issue:
Call connected, no audio

Debug Flow:
- SIP OK (200 OK received)
- RTP missing one direction
- tcpdump confirmed issue

Fix:
rtp_symmetric=yes
rewrite_contact=yes
direct_media=no

Result:
✔ Audio restored
✔ Stable RTP
✔ Issues reduced ~70%
```
